# Código de Conducta

[**English**](CODE_OF_CONDUCT.md) · [**Español**](CODE_OF_CONDUCT.es.md)

## Comportamiento Esperado
Se espera que los colaboradores y mantenedores que participen en los debates, issues y pull requests de SoundChord:
- Se comuniquen de manera constructiva y profesional.
- Traten a los demás colaboradores, mantenedores y usuarios con respeto.
- Se centren en los méritos técnicos y en lo que sea mejor para el proyecto.
- Acepten las críticas constructivas con buena disposición.

## Comportamiento Inaceptable
Los siguientes comportamientos son inaceptables dentro del proyecto:
- Acoso, comentarios despectivos o ataques personales.
- Troleo, insultos o comportamiento disruptivo.
- Publicación de información privada de otros sin consentimiento explícito.
- Atención o avances sexuales no deseados, o lenguaje inapropiado.

## Cómo Reportar
Si experimentas o eres testigo de un comportamiento inaceptable, infórmalo de manera privada al mantenedor del proyecto:
- Correo electrónico: `808andrex@gmail.com`

Los reportes se manejarán de forma privada y con la debida discreción.

## Aplicación y Moderación
El mantenedor del proyecto se reserva el derecho de:
- Eliminar, editar o rechazar comentarios, commits, código, issues o pull requests que violen este código de conducta.
- Restringir o bloquear de forma temporal o permanente la participación en los repositorios del proyecto ante infracciones reiteradas o graves.
